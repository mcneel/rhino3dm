Interface RhinoModuleOptions

Optional locateFile

locateFile?: ((path, scriptDirectory) => string)

Override where rhino3dm.wasm is loaded from. Receives the file name ('rhino3dm.wasm') and the directory the script was loaded from, and must return the URL to fetch. Use this when a bundler (Vite, webpack, Next.js, ...) does not serve the .wasm next to the .js.

Type declaration

    • Parameters

      • scriptDirectory: string

      Returns string

Example

const rhino = await rhino3dm({ locateFile: (file) => `/wasm/${file}` });
