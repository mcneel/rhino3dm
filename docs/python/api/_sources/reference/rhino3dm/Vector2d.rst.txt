rhino3dm.Vector2d
=================

.. py:class:: rhino3dm.Vector2d
              Vector2d(x: float, y: float)

   Represents the two components of a vector in two-dimensional space, using ``double``-precision floating point numbers.

   .. py:method:: CompareTo(other: Vector2d) -> int

      Compares this ``Vector2d`` with another ``Vector2d``.

      Components evaluation priority is first X, then Y.

      :param other: The other ``Vector2d`` to use in comparison.

      :returns: if this is identical to other
                -1: if this.X < other.X
                -1: if this.X == other.X and this.Y < other.Y
                +1: otherwise.
      :rtype: 0

      :staticmethod:


      Multiplies two vectors together, returning the dot product (or inner product).

      (Provided for languages that do not support operator overloading. You can use the \* operator otherwise)

      :param vector1: A vector.
      :param vector2: A second vector.

      :returns: A value that results from the evaluation of v1.X\*v2.X + v1.Y\*v2.Y.
                This value equals v1.Length \* v2.Length \* cos(alpha), where alpha is the angle between vectors.
