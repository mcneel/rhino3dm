rhino3dm.ComponentIndex
=======================

.. py:class:: rhino3dm.ComponentIndex
              ComponentIndex(type: ComponentIndexType, index: int)

   Represents an index of an element contained in another object.


   .. py:method:: CompareTo(other: ComponentIndex) -> int

      Compares this ``ComponentIndex`` with another ``ComponentIndex``.

      :param other: The other ``ComponentIndex`` to use in comparison

      :returns: if this is identical to other
                -1: if this.ComponentIndexType < other.ComponentIndexType
                -1: if this.ComponentIndexType == other.ComponentIndexType and this.Index < other.Index
                +1: otherwise.
      :rtype: 0



   .. py:method:: Equals(other: ComponentIndex) -> bool

      Determines whether the specified ``ComponentIndex`` is equal to the current ``ComponentIndex``, comparing by value.

      :param other: The other ``ComponentIndex`` to compare with.

      :returns: true if other has the same ComponentIndexType and Index as this; otherwise, false.



   .. py:method:: IsUnset() -> bool
