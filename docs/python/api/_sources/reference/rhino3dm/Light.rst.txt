rhino3dm.Light
==============

.. py:class:: rhino3dm.Light

   Bases: :py:obj:`GeometryBase`


   Represents a light that shines in the modeling space.


   .. py:method:: GetAttenuation(d: float) -> float

      Gets the attenuation settings (ignored for "directional" and "ambient" lights).

      attenuation = 1/(a0 + d\*a1 + d^2\*a2) where d = distance to light.

      :param d: The distance to evaluate.

      :returns: 0 if a0 + d\*a1 + d^2\*a2 <= 0.



   .. py:method:: GetSpotLightRadii() -> tuple[bool, float, float]

      Gets the spot light radii.

      :returns: true if operation succeeded; otherwise, false.



   .. py:method:: SetAttenuation(a0: float, a1: float, a2: float) -> None

      Sets the attenuation settings (ignored for "directional" and "ambient" lights).

      attenuation = 1/(a0 + d\*a1 + d^2\*a2) where d = distance to light.

      :param a0: The new constant attenuation divisor term.
      :param a1: The new reverse linear attenuation divisor term.
      :param a2: The new reverse quadratic attenuation divisor term.

      The hot spot setting runs from 0.0 to 1.0 and is used to provides a linear interface for controlling the focus or concentration of a spotlight. A hot spot setting of 0.0 corresponds to a spot exponent of 128. A hot spot setting of 1.0 corresponds to a spot exponent of 0.0.

   .. py:property:: SpotExponent
      :type: float


      The spot exponent varies from 0.0 to 128.0 and provides an exponential interface for controlling the focus or concentration of a spotlight (like the OpenGL GL\_SPOT\_EXPONENT parameter). The spot exponent and hot spot parameters are linked; changing one will change the other. A hot spot setting of 0.0 corresponds to a spot exponent of 128. A hot spot setting of 1.0 corresponds to a spot exponent of 0.0.
