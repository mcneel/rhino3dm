rhino3dm.File3dmEmbeddedFile
============================

.. py:class:: rhino3dm.File3dmEmbeddedFile

   Bases: :py:obj:`ModelComponent`


   Base class for all components in a model (document) and manages the index, id and other information common to this type of objects.

   This class parallels the C++ ON\_ModelComponent.


   .. py:method:: Clear() -> bool

      Clears the embedded file data.

      :returns: true if successful, else false.



   .. py:method:: Read(fileName: str) -> File3dmEmbeddedFile
      :staticmethod:


      An embedded file loaded from disk, ready to add to a model (rhino3dm only).

      :param fileName: The file to load.

      :returns: The embedded file, or None when the file cannot be read.



   .. py:method:: SaveToFile(filename: str) -> bool

      Saves the contents of the embedded file to a local file. Returns true if successful, else false.



   .. py:method:: ToByteArray() -> bytes

      The embedded file's bytes (rhino3dm only): empty when it has no data. JS gets a Uint8Array, Python bytes.



   .. py:property:: ComponentType
      :type: ModelComponentType


      Returns ``ModelComponentType.EmbeddedFile``.


   .. py:property:: CompressedLength
      :type: int


      The number of bytes this file occupies in the archive. Returns zero when the embedded file was not loaded from an archive (e.g. when it was loaded from a local file or buffer).


   .. py:property:: Filename
      :type: str


      the fully-qualified filename of the embedded file. This filename may or may not refer to a local file depending on the way the embedded file was loaded. For example, if it was loaded from an archive, the filename could be that of a file on a different computer.


   .. py:property:: Length
      :type: int


      Gets the length of the loaded data, or zero if the embedded file is not loaded.
