rhino3dm.GeometryBase
=====================

.. py:class:: rhino3dm.GeometryBase

   Bases: :py:obj:`CommonObject`


   Provides a common base for most geometric classes. This class is abstract.


   .. py:method:: ComponentIndex() -> ComponentIndex

      If this piece of geometry is a component in something larger, like a BrepEdge in a Brep, then this function returns the component index.

      :returns: This object's component index. If this object is not a sub-piece of a larger geometric entity, then the returned index has m\_type = ComponentIndex.InvalidType and m\_index = -1.



   .. py:method:: DataCRC(currentRemainder: int) -> int

      Returns a CRC calculated from the information that defines the object. This CRC can be used as a quick way to see if two objects are not identical.

      :param currentRemainder: The current remainder value.

      :returns: CRC of the information the defines the object.



   .. py:method:: DeleteAllUserStrings() -> None


   .. py:method:: Duplicate() -> GeometryBase

      Constructs a deep (full) copy of this object.

      :returns: An object of the same type as this, with the same properties and behavior.



   .. py:method:: GetBoundingBox(xform: Transform) -> BoundingBox
                  GetBoundingBox(plane: Plane) -> BoundingBox
                  GetBoundingBox(accurate: bool) -> BoundingBox

      Bounding box solver. Gets the world axis aligned bounding box for the geometry.

      :param accurate: If true, a physically accurate bounding box will be computed. If not, a bounding box estimate will be computed. For some geometry types there is no difference between the estimate and the accurate bounding box. Estimated bounding boxes can be computed much (much) faster than accurate (or "tight") bounding boxes. Estimated bounding boxes are always similar to or larger than accurate bounding boxes.

      :returns: The bounding box of the geometry in world coordinates or BoundingBox.Empty if not bounding box could be found.



   .. py:method:: GetUserString(key: str) -> str

      Gets user string from this geometry.

      :param key: id used to retrieve the string.

      :returns: string associated with the key if successful. null if no key was found.



   .. py:method:: GetUserStrings() -> list[Any]

      Gets a copy of all (user key string, user value string) pairs attached to this geometry.

      :returns: A new collection.



   .. py:method:: MakeDeformable() -> bool

      If possible, converts the object into a form that can be accurately modified with "squishy" transformations like projections, shears, an non-uniform scaling.

      :returns: false if object cannot be converted to a deformable object. true if object was already deformable or was converted into a deformable object.



   .. py:method:: MemoryEstimate() -> int

      Computes an estimate of the number of bytes that this object is using in memory.

      :returns: An estimated memory footprint.



   .. py:method:: Rotate(angleRadians: float, rotationAxis: Vector3d, rotationCenter: Point3d) -> bool

      Rotates the object about the specified axis. A positive rotation angle results in a counter-clockwise rotation about the axis (right hand rule).

      :param angleRadians: Angle of rotation in radians.
      :param rotationAxis: Direction of the axis of rotation.
      :param rotationCenter: Point on the axis of rotation.

      :returns: true if geometry successfully rotated.



   .. py:method:: Scale(scaleFactor: float) -> bool

      Scales the object by the specified factor. The scale is centered at the origin.

      :param scaleFactor: The uniform scaling factor.

      :returns: true if geometry successfully scaled.



   .. py:method:: SetUserString(key: str, value: str) -> bool

      Attach a user string (key,value combination) to this geometry.

      :param key: id used to retrieve this string.
      :param value: string associated with key.

      :returns: true on success.



   .. py:method:: Transform(xform: Transform) -> bool

      Transforms the geometry. If the input Transform has a SimilarityType of OrientationReversing, you may want to consider flipping the transformed geometry after calling this function when it makes sense. For example, you may want to call Flip() on a Brep after transforming it.

      :param xform: Transformation to apply to geometry.

      :returns: true if geometry successfully transformed.



   .. py:method:: Translate(translationVector: Vector3d) -> bool
                  Translate(x: float, y: float, z: float) -> bool

      Translates the object along the specified vector.

      :param x: The X component.
      :param y: The Y component.
      :param z: The Z component.

      :returns: true if geometry successfully translated.
