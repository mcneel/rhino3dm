      :param vector: A vector.

   .. py:method:: CompareTo(other: Point3d) -> int

      Compares this ``Point3d`` with another ``Point3d``.

      Component evaluation priority is first X, then Y, then Z.

      :param other: The other ``Point3d`` to use in comparison.

      :returns: if this is identical to other
                -1: if this.X < other.X
                -1: if this.X == other.X and this.Y < other.Y
                -1: if this.X == other.X and this.Y == other.Y and this.Z < other.Z
                +1: otherwise.
      :rtype: 0



   .. py:method:: DistanceTo(other: Point3d) -> float

      Computes the distance between two points.

      :param other: Other point for distance measurement.

      :returns: The length of the line between this and the other point; or 0 if any of the points is not valid.



   .. py:method:: DistanceToSquared(other: Point3d) -> float

      Computes the square of the distance between two points.

      This method is usually largely faster than DistanceTo().

      :param other: Other point for squared distance measurement.

      :returns: The squared length of the line between this and the other point; or 0 if any of the points is not valid.
