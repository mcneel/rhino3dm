rhino3dm.File3dm
================

.. py:class:: rhino3dm.File3dm

   Represents a 3dm file, which is stored using the OpenNURBS file standard.

   The 3dm format is the main Rhinoceros storage format.

   Visit http://www.opennurbs.com/ for more details.

      :returns: The model, or None when the bytes are not a .3dm file.

   .. py:method:: GetEmbeddedFileAsBase64(path: str) -> str
                  GetEmbeddedFileAsBase64(path: str, strict: bool) -> str

      The bytes of a file embedded in the model, base64 encoded (rhino3dm only).

      Finds only the files Rhino's renderer embedded, not ones added with EmbeddedFiles.Add. To read any embedded file, take it from File3dm.EmbeddedFiles and call its ToByteArray().

      :param path: The embedded file's path, or (not strict) just its name.
      :param strict: True: the path must match exactly, case included. False (the default): the path or the file name matches, ignoring case.

      :returns: The file's bytes as a base64 string, empty when no embedded file matches.

   .. py:method:: Write(path: str, options: File3dmWriteOptions | None) -> bool
                  Write(path: str, version: int) -> bool

      Writes contents of this model to an openNURBS archive. If the model is not valid, then Write will refuse to write it.

      :param path: The file name to use for writing.
      :param version: Version of the openNURBS archive to write. Must be [2; current version]. Rhino can read its current version, plus earlier file versions except 1. Use latest version when possible.
                      Alternatively, 0 is a placeholder for the last valid version.

      :returns: true if archive is written with no error. false if errors occur.



   .. py:method:: WriteMultipleObjects(path: str, geometry: collections.abc.Sequence[GeometryBase] | None) -> bool
      :staticmethod:


      Creates a simple 3dm file that contains a multiple geometric objects.

      :param path: Path to the 3dm file to create.
      :param geometry: The geometry to be saved in the archive's object table. This is typically some Curves, Surfaces, Breps, Meshs, or SubDs.

      :returns: True if successful, false otherwise.



   .. py:method:: WriteOneObject(path: str, geometry: GeometryBase) -> bool
      :staticmethod:


      Creates a simple 3dm file that contains a single geometric object.

      :param path: Path to the 3dm file to create.
      :param geometry: The geometry to be saved in the archive's object table. This is typically a Curve, Surface, Brep, Mesh, or SubD.

      :returns: True if successful, false otherwise.
