      Creates a SubD form of a cylinder.

      :param cylinder: The defining cylinder.
      :param circumferenceFaceCount: Number of faces around the cylinder.
      :param heightFaceCount: Number of faces in the top-to-bottom direction.
      :param endCapStyle: The end cap style.
      :param endCapEdgeTag: The end cap edge tag.
      :param radiusLocation: The SubD component location.

      :returns: A new SubD if successful, or null on failure.
