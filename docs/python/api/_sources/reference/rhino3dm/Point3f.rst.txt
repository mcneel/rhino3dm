rhino3dm.Point3f
================

.. py:class:: rhino3dm.Point3f
              Point3f(x: float, y: float, z: float)

   Represents the three coordinates of a point in three-dimensional space, using ``Single``-precision floating point numbers.


   .. py:method:: Add(point1: Point3f, point2: Point3f) -> Point3f

      Sums up a point and a vector, and returns a new point.

      (Provided for languages that do not support operator overloading. You can use the + operator otherwise)

      :param point: A point.
      :param vector: A vector.

      :returns: A new point that results from the addition of point and vector.



   .. py:method:: CompareTo(other: Point3f) -> int

      Compares this ``Point3f`` with another ``Point3f``.

      Component evaluation priority is first X, then Y, then Z.

      :param other: The other ``Point3d`` to use in comparison.

      :returns: if this is identical to other
                -1: if this.X < other.X
                -1: if this.X == other.X and this.Y < other.Y
                -1: if this.X == other.X and this.Y == other.Y and this.Z < other.Z
                +1: otherwise.
      :rtype: 0



   .. py:method:: DistanceTo(other: Point3f) -> float

      Computes the distance between two points.

      :param other: Other point for distance measurement.

      :returns: The length of the line between this and the other point; or 0 if any of the points is not valid.



   .. py:method:: DistanceToSquared(other: Point3f) -> float
