   .. py:method:: FromRichTextProperties(richTextFontName: str, bold: bool, italic: bool, underlined: bool, strikethrough: bool) -> Font
      :staticmethod:


      Returns a font with the requested rich-text (family) name, preserving that name even when the font is not installed on the current machine. If an installed font matches it is returned; otherwise a "not on device" managed font that keeps the requested name is returned (rendered with a fallback quartet). Use this to author a font by name on a machine that does not have it installed: the Font constructor and ``FromQuartetProperties`` both substitute the family in that case, losing the requested name when the file is written.

      :param richTextFontName: The rich-text font (family) name to store.
      :param bold: True to select the heavier member of the rich-text quartet.
      :param italic: True to select the more slanted member of the rich-text quartet.
      :param underlined: True for underlined text.
      :param strikethrough: True for strikethrough text.

      :returns: A font that preserves the requested name, or null if none could be created.

   .. py:property:: AscentOfCapital
      :type: int


      The font's typographic capital height, in the design units reported by ``UnitsPerEm``. This is the metric a "text height" is measured against, so text of height h renders its capitals h tall. Zero when the font has no usable metrics.

   .. py:property:: UnitsPerEm
      :type: int


      The number of design units per em in this font's normalized metrics. Together with ``AscentOfCapital`` this converts between an em size - the "font size" used by CSS, SVG, PDF and most page layout - and the height of a capital letter, which is what Rhino means by a text height. Zero when the font has no usable metrics.
