rhino3dm.Surface
================

.. py:class:: rhino3dm.Surface

   Bases: :py:obj:`GeometryBase`


   Represents a base class that is common to most RhinoCommon surface types.

   A surface represents an entity that can be all visited by providing two independent parameters, usually called (u, v), or sometimes (s, t).


   .. py:method:: Degree(direction: int) -> int

      Returns the maximum algebraic degree of any span (or a good estimate if curve spans are not algebraic).

      :param direction: 0 gets first parameter's domain, 1 gets second parameter's domain.

      :returns: The maximum degree.



   .. py:method:: Domain(direction: int) -> Interval

   .. py:method:: Evaluate(u: float, v: float, numberDerivatives: int) -> tuple[bool, Point3d, list[Vector3d]]

      Evaluates a surface mathematically.

      The partial derivatives will be in the order {Su, Sv} for numberDerivatives = 1, {Su, Sv, Suu, Suv, Svv} for 2, {Su, Sv, Suu, Suv, Svv, Suuu, Suuv, Suvv, Svvv} for 3, and similar for higher counts.

      :param u: A U parameter.
      :param v: A V parameter.
      :param numberDerivatives: The number of derivatives.

      :returns: true if the operation succeeded; false otherwise.



   .. py:method:: Extend(direction: int, interval: Interval) -> bool

      Analytically extends the surface to include the interval.

      :param direction: If 0, Surface.Domain(0) will include the interval. (the first surface parameter). If 1, Surface.Domain(1) will include the interval. (the second surface parameter).
      :param interval: If the interval is not included in surface domain, the surface will be extended so that its domain includes the interval. Note, this method will fail if the surface is closed in the specified direction.

      :returns: True if successful, false otherwise.

      :param u: A first parameter.
      :param v: A second parameter.

      :returns: true if this operation succeeded; otherwise false.



   .. py:method:: GetNextDiscontinuity(direction: int, continuityType: Continuity, t0: float, t1: float, cosAngleTolerance: float, curvatureTolerance: float) -> tuple[bool, float]
                  GetNextDiscontinuity(direction: int, continuityType: Continuity, t0: float, t1: float) -> tuple[bool, float]

      Searches for a derivative, tangent, or curvature discontinuity.

      :param direction: If 0, then "u" parameter is checked. If 1, then the "v" parameter is checked.
      :param continuityType: The desired continuity.
      :param t0: Search begins at t0. If there is a discontinuity at t0, it will be ignored. This makes it possible to repeatedly call GetNextDiscontinuity and step through the discontinuities.
      :param t1: (t0 != t1) If there is a discontinuity at t1 is will be ignored unless c is a locus discontinuity type and t1 is at the start or end of the curve.

      :returns: TRUE if a parametric discontinuity was found strictly between t0 and t1. Note well that all curves are parametrically continuous at the ends of their domains.
                Locus continuity tests c = (C0\_locus\_continuous, ...,G2\_locus\_continuous): TRUE if a locus discontinuity was found strictly between t0 and t1 or at t1 is the at the end of a curve. Note well that all open curves (IsClosed()=false) are locus discontinuous at the ends of their domains. All closed curves (IsClosed()=true) are at least C0\_locus\_continuous at the ends of their domains.
      :rtype: Parametric continuity tests c = (C0\_continuous, ..., G2\_continuous)

   .. py:method:: HasNurbsForm() -> int

      Is there a NURBS surface representation of this surface.

      :returns: 0 unable to create NURBS representation with desired accuracy. 1 success - NURBS parameterization matches the surface's 2 success - NURBS point locus matches the surface's and the domain of the NURBS surface is correct. However, This surface's parameterization and the NURBS surface parameterization may not match. This situation happens when getting NURBS representations of surfaces that have a transcendental parameterization like spheres, cylinders, and cones.



   .. py:method:: IsAtSeam(u: float, v: float) -> int

      Tests if a surface parameter value is at a seam.

      :param u: Surface u parameter to test.
      :param v: Surface v parameter to test.

      :returns: 0 if not a seam, 1 if u == Domain(0)[i] and srf(u, v) == srf(Domain(0)[1-i], v) 2 if v == Domain(1)[i] and srf(u, v) == srf(u, Domain(1)[1-i]) 3 if 1 and 2 are true.

   .. py:method:: IsoCurve(iso: IsoStatus) -> Curve
                  IsoCurve(iso: IsoStatus, t: float) -> Curve
                  IsoCurve(direction: int, constantParameter: float) -> Curve

      Gets isoparametric curve.

      In this function "direction" indicates which direction the resulting curve runs. 0: horizontal, 1: vertical In the other Surface functions that take a "direction" argument, "direction" indicates if "constantParameter" is a "u" or "v" parameter.

      :param direction: 0 first parameter varies and second parameter is constant e.g., point on IsoCurve(0,c) at t is srf(t,c) This is a horizontal line from left to right
                        1 first parameter is constant and second parameter varies e.g., point on IsoCurve(1,c) at t is srf(c,t This is a vertical line from bottom to top.
      :param constantParameter: The parameter that was constant on the original surface.

      :returns: An isoparametric curve or null on error.

   .. py:method:: TryGetCylinder(tolerance: float) -> tuple[bool, Cylinder]
                  TryGetCylinder() -> tuple[bool, Cylinder]

      Tests a surface to see if it is a portion of a cylinder within RhinoMath.ZeroTolerance and return the cylinder.

      If successful, an infinite cylinder is returned. When a surface has a cylindrical shape, even if its ends are not circles on the cylinder, it returns the axis and radius. You can detect infinite cylinders using Cylinder.IsFinite.

      :returns: true if the surface is a portion of a cylinder.

      :returns: true if the surface is a portion of a cylinder.
