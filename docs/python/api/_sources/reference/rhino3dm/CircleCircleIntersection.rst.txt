rhino3dm.CircleCircleIntersection
=================================

.. py:class:: rhino3dm.CircleCircleIntersection

   Bases: :py:obj:`enum.IntEnum`


   Represents all possible cases of a Circle\|Circle intersection event.


   .. py:attribute:: Multiple
      :value: 2


      Circles intersect at two points.


   .. py:attribute:: None_
      :value: 0


      RhinoCommon's ``None`` (``CircleCircleIntersection.None`` is not Python syntax; ``CircleCircleIntersection['None']`` is the same member). Circles do not intersect.


   .. py:attribute:: Overlap
      :value: 3


      Circles are identical.


   .. py:attribute:: Single
      :value: 1


      Circles touch at a one point.
