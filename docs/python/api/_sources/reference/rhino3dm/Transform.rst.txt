      :staticmethod:


      Gets a change of basis transformation. The change of basis transformation is not the same as the rotation transformation that rotates one orthonormal frame to another.

      Change of basis transformations and rotation transformations are often confused. This is a change of basis transformation. If Q = P0 + a0\*X0 + b0\*Y0 + c0\*Z0 = P1 + a1\*X1 + b1\*Y1 + c1\*Z1, then this transform will map the point (a0,b0,c0) to (a1,b1,c1).

      :param P0: Initial center.
      :param X0: Initial basis X (can be any 3d basis).
      :param Y0: Initial basis Y (can be any 3d basis).
      :param Z0: Initial basis Z (can be any 3d basis).
      :param P1: Final center.
      :param X1: Final basis X (can be any 3d basis).
      :param Y1: Final basis Y (can be any 3d basis).
      :param Z1: Final basis Z (can be any 3d basis).

      :returns: A change of basis transformation if success, ``Transform.Unset`` on failure.

   .. py:method:: DecomposeAffine() -> tuple[bool, Transform, Vector3d]

      Decomposes an affine transformation. A transformation is affine if it is valid and its last row is [0, 0, 0, 1]. An affine transformation can be broken into a linear transformation and a translation. Note, a perspective transformation is not affine.

      If X.DecomposeAffine(L, T) is true then X == L\* Translation(T). DecomposeAffine(L, T) may fail for affine transformations if L is not invertible, and is more computationally expensive then X.DecomposeAffine(T, L).

      :returns: True if successful decomposition.



   .. py:method:: DecomposeAffineFull() -> tuple[bool, Vector3d, Transform, Transform, Vector3d]

      An affine transformation can be decomposed into a Symmetric, Rotation and Translation. Then the Symmetric component may be further decomposed as non-uniform scale in an orthonormal coordinate system.

      :returns: True if successful decomposition.



   .. py:method:: DecomposeRigid(tolerance: float) -> tuple[TransformRigidType, Vector3d, Transform]

      Decomposes a rigid transformation. The transformation must be affine.

      If X.DecomposeRigid(T, R) is 1, then X ~ Translation(T)\*R. If X.DecomposeRigid(T, R) is -1, then X ~ Transform(-1) \* Translation(T)\*R. DecomposeRigid will find the closest rotation to the linear part of this transformation.

      :param tolerance: The evaluation tolerance.

      :returns: The rigid type.



   .. py:method:: DecomposeSimilarity(tolerance: float) -> tuple[TransformSimilarityType, Vector3d, float, Transform]

      Decomposes a similarity transformation. The transformation must be affine. A similarity transformation can be broken into a sequence of a dilation, translation, rotation, and a reflection.

      If X.DecomposeSimilarity(T, d, R, tol) !=0 then X ~ Translation(T)\*Diagonal(d)\*R note when d gt;0 the transformation is orientation preserving. If dilation lt; 0 then Diagonal(dilation) is actually a reflection combined with a true dilation, or Diagonal(dilation) = Diagonal(-1) \* Diagonal(\|diagonal\|).

      :param tolerance: The evaluation tolerance.

      :returns: The similarity type.



   .. py:method:: DecomposeSymmetric() -> tuple[bool, Transform, Vector3d]

      A Symmetric linear transformation can be decomposed A = Q \* Diag \* Q ^ T, where Diag is a diagonal transformation. Diag[i][i] is an eigenvalue of A and the i-th column of Q is a corresponding unit length eigenvector. Note, this transformation must be Linear and Symmetric.

      If success, this== Q\*Diagonal(diagonal) \* QT, where QT == Q.Transpose(). If L.IsLinear and LT==L.Transpose then LT\*L is symmetric and is a common source of symmetric transformations.

      :returns: true if successful, false otherwise.

      :param y0: Initial frame Y.

      :param z1: Final frame Z.

      :returns: A rotation transformation matrix.



   .. py:method:: RotationZYX(yaw: float, pitch: float, roll: float) -> Transform
      :staticmethod:


      Create rotation transformation From Tait-Byran angles (also loosely known as Euler angles).

      RotationZYX(yaw, pitch, roll) = R\_z(yaw) \* R\_y(pitch) \* R\_x(roll) where R\_\*(angle) is rotation of angle radians about the corresponding world coordinate axis.

      :param yaw: Angle, in radians, to rotate about the Z axis.
      :param pitch: Angle, in radians, to rotate about the Y axis.
      :param roll: Angle, in radians, to rotate about the X axis.

      :returns: A transform matrix from Tait-Byran angles.



   .. py:method:: RotationZYZ(alpha: float, beta: float, gamma: float) -> Transform
      :staticmethod:


      Create rotation transformation From Euler angles.

      RotationZYZ(alpha, beta, gamma) = R\_z(alpha) \* R\_y(beta) \* R\_z(gamma) where R\_\*(angle) is rotation of angle radians about the corresponding \*-world coordinate axis. Note, alpha and gamma are in the range (-pi, pi] while beta in the range [0, pi]

      :param alpha: Angle, in radians, to rotate about the Z axis.
      :param beta: Angle, in radians, to rotate about the Y axis.
      :param gamma: Angle, in radians, to rotate about the X axis.

      :returns: A transform matrix from Euler angles.
