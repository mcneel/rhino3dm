rhino3dm.Vector3d
=================

   .. py:method:: CompareTo(other: Vector3d) -> int

      Compares this ``Vector3d`` with another ``Vector3d``.

      Component evaluation priority is first X, then Y, then Z.

      :param other: The other ``Vector3d`` to use in comparison.

      :returns: if this is identical to other
                -1: if this.X < other.X
                -1: if this.X == other.X and this.Y < other.Y
                -1: if this.X == other.X and this.Y == other.Y and this.Z < other.Z
                +1: otherwise.
      :rtype: 0



   .. py:method:: CrossProduct(a: Vector3d, b: Vector3d) -> Vector3d
      :staticmethod:


      Computes the cross product (or vector product, or exterior product) of two vectors.

      This operation is not commutative.

      :param a: First vector.
      :param b: Second vector.

      :returns: A new vector that is perpendicular to both a and b,
                has Length == a.Length \* b.Length \* sin(theta) where theta is the angle between a and b.
                The resulting vector is oriented according to the right hand rule.

   .. py:method:: Multiply(vector: Vector3d, t: float) -> Vector3d
                  Multiply(t: float, vector: Vector3d) -> Vector3d
                  Multiply(vector1: Vector3d, vector2: Vector3d) -> float
      :staticmethod:


      Multiplies two vectors together, returning the dot product (or inner product). This differs from the cross product.

      (Provided for languages that do not support operator overloading. You can use the \* operator otherwise)

      :param vector1: A vector.
      :param vector2: A second vector.

      :returns: A value that results from the evaluation of v1.X\*v2.X + v1.Y\*v2.Y + v1.Z\*v2.Z.
                This value equals v1.Length \* v2.Length \* cos(alpha), where alpha is the angle between vectors.

      (Provided for languages that do not support operator overloading. You can use the - unary operator otherwise)

      :param vector: A vector to negate.

      :returns: A new vector where all components were multiplied by -1.
