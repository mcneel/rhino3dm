rhino3dm.Interval
=================

.. py:class:: rhino3dm.Interval
              Interval(t0: float, t1: float)
              Interval(arg: Interval)
              Interval(arg: collections.abc.Sequence[Any], /)

   Represents an interval in one-dimensional space, that is defined as two extrema or bounds.


   .. py:method:: CompareTo(other: Interval) -> int

      Compares this ``Interval`` with another interval.

      The lower bound has first evaluation priority.

      :param other: The other ``Interval`` to compare with.

      :returns: if this is identical to other
                -1: if this[0] < other[0]
                +1: if this[0] > other[0]
                -1: if this[0] == other[0] and this[1] < other[1]
                +1: if this[0] == other[0] and this[1] > other[1]
                .
      :rtype: 0

   .. py:method:: Equals(other: Interval) -> bool

      Determines whether the specified ``Interval`` is equal to the current ``Interval``, comparing by value.

      :param other: The other interval to compare with.

      :returns: true if obj is an ``Interval`` and has the same bounds; false otherwise.



   .. py:method:: Expand(value: float) -> None

      Expand an interval by adding the value to T1 and subtracting it from T0. If T1 < T0, T0 and T1 are swapped.



   .. py:method:: FromIntersection(a: Interval, b: Interval) -> Interval
      :staticmethod:


      Returns a new Interval that is the Intersection of the two input Intervals.

      :param a: The first input interval.
      :param b: The second input interval.

      :returns: If the intersection is not empty, then intersection = [max(a.Min(),b.Min()), min(a.Max(),b.Max())] The interval [ON.UnsetValue,ON.UnsetValue] is considered to be the empty set interval. The result of any intersection involving an empty set interval or disjoint intervals is the empty set interval.



   .. py:method:: FromUnion(a: Interval, b: Interval) -> Interval
      :staticmethod:


      Returns a new Interval which contains both inputs.

      :param a: The first input interval.
      :param b: The second input interval.

      :returns: The union of an empty set and an increasing interval is the increasing interval.
                The union of two empty sets is empty.
                The union of an empty set an a non-empty interval is the non-empty interval.
                The union of two non-empty intervals is [min(a.Min(),b.Min()), max(a.Max(),b.Max())]
