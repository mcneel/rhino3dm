rhino3dm.LineCircleIntersection
===============================

.. py:class:: rhino3dm.LineCircleIntersection

   Bases: :py:obj:`enum.IntEnum`


   Represents all possible cases of a Line\|Circle intersection event.


   .. py:attribute:: Multiple
      :value: 2


      Two intersections.


   .. py:attribute:: None_
      :value: 0


      RhinoCommon's ``None`` (``LineCircleIntersection.None`` is not Python syntax; ``LineCircleIntersection['None']`` is the same member). No intersections.


   .. py:attribute:: Single
      :value: 1


      One intersection.
