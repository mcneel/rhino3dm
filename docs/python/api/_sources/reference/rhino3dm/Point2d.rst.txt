================

   .. py:method:: CompareTo(other: Point2d) -> int

      Compares this ``Point2d`` with another ``Point2d``.

      Coordinates evaluation priority is first X, then Y.

      :param other: The other ``Point2d`` to use in comparison.

      :returns: if this is identical to other
                -1: if this.X < other.X
                -1: if this.X == other.X and this.Y < other.Y
                +1: otherwise.
      :rtype: 0



   .. py:method:: DistanceTo(other: Point2d) -> float

      Computes the distance between two points.

      :param other: Another point.

      :returns: The length of the line between the two points, or 0 if either point is invalid.



   .. py:method:: DistanceToSquared(other: Point2d) -> float

      Computes the square of the distance between two 2d points.

      This method is usually largely faster than DistanceTo().

      :param other: Other point for squared distance measurement.

      :returns: The squared length of the line between this and the other point; or 0 if any of the points is not valid.
