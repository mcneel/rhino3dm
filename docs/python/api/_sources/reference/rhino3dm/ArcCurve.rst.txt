rhino3dm.ArcCurve
=================

   Bases: :py:obj:`Curve`


   Represent arcs and circles.

   ArcCurve.IsCircle returns true if the curve is a complete circle.

   Details:

   an ArcCurve is a sub-curve of a circle, with a constant speed parameterization. The parameterization is an affine linear reparameterization of the underlying arc m\_arc onto the domain m\_t.

   A valid ArcCurve has Radius()>0 and 0<AngleRadians()<=2\*PI and a strictly increasing Domain.
