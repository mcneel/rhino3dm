   .. py:method:: Create(dimension: int, isRational: bool, order0: int, order1: int, controlPointCount0: int, controlPointCount1: int) -> NurbsSurface
      :staticmethod:


      Constructs a new NURBS surface with internal uninitialized arrays.

      :param dimension: The number of dimensions.
                        >= 1. This value is usually 3.
      :param isRational: true to make a rational NURBS.
      :param order0: The order in U direction.
                     >= 2.
      :param order1: The order in V direction.
                     >= 2.
      :param controlPointCount0: Control point count in U direction.
                                 >= order0.
      :param controlPointCount1: Control point count in V direction.
                                 >= order1.

      :returns: A new NURBS surface, or null on error.
