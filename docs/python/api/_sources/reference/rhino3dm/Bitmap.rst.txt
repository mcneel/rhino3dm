rhino3dm.Bitmap
===============

.. py:class:: rhino3dm.Bitmap

   Bases: :py:obj:`ModelComponent`

      Attaches a named string to this object (rhino3dm only).

      :param value: The text; an empty string removes the key.

      :returns: True on success.
