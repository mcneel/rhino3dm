rhino3dm.Box
============

   .. py:method:: ClosestPoint(point: Point3d) -> Point3d
                  ClosestPoint(point: Point3d, includeInterior: bool) -> Point3d

      Finds the closest point on or in the Box. The box should be Valid for this to work.

      :param point: Sample point.
      :param includeInterior: If false, the point is projected onto the boundary faces only, otherwise the interior of the box is also taken into consideration.

      :returns: The point on or in the box that is closest to the sample point.



   .. py:method:: Contains(point: Point3d) -> bool
                  Contains(point: Point3d, strict: bool) -> bool
                  Contains(box: BoundingBox) -> bool
                  Contains(box: BoundingBox, strict: bool) -> bool
                  Contains(box: Box) -> bool
                  Contains(box: Box, strict: bool) -> bool

      Determines whether a BoundingBox is inside this Box (strict inclusion, if strict is true). Invalid boxes contain nothing. Invalid bounding boxes are never contained.

      :param box: BoundingBox to test.
      :param strict: If true, the BoundingBox needs to be strictly inside this Box, i.e. all corners of the BoundingBox are strictly inside this Box. If false, the BoundingBox can be touching this Box's boundary, i.e. all corners of the BoundingBox are non-strictly inside this Box.

      :returns: true if the box is (strictly, if strict is true) inside this Box. false if this Box or the BoundingBox are invalid.

   .. py:method:: Inflate(amount: float) -> None
                  Inflate(xAmount: float, yAmount: float, zAmount: float) -> None

      Inflates the box by a given offset in each direction. Inflating with negative amounts may result in decreasing boxes. InValid boxes cannot be inflated.

      :param xAmount: Amount (in model units) to inflate this box in the x direction.
      :param yAmount: Amount (in model units) to inflate this box in the y direction.
      :param zAmount: Amount (in model units) to inflate this box in the z direction.



   .. py:method:: MakeValid() -> bool

      DO NOT USE THIS FUNCTION If some of the box's values (Plane origin or axis, intervals bounds) are unset, do nothing. Else, make the Box valid by reversing the non-increasing intervals of this box. This is almost never what you want because it only makes ``Empty``\ Empty boxes not empty and with non-zero length.

      :returns: true if the box was made valid, or if it was valid to begin with. false if the box remains unchanged.

      Deprecated since 9.0.



   .. py:method:: PointAt(x: float, y: float, z: float) -> Point3d

      Evaluates the box at the given unitized parameters.

      The box is parametrized with a side length of 1x1x1.

      :param x: Unitized parameter (between 0 and 1 is inside the box) along box X direction.
      :param y: Unitized parameter (between 0 and 1 is inside the box) along box Y direction.
      :param z: Unitized parameter (between 0 and 1 is inside the box) along box Z direction.

      :returns: The point at (x,y,z).



   .. py:method:: RepositionBasePlane(origin: Point3d) -> None

   .. py:method:: Transform(xform: Transform) -> bool

      Transforms this Box using a Transformation matrix. If the Transform is not a Similarity, the dimensions of the resulting box cannot be trusted.

      :param xform: Transformation matrix to apply to this Box.

      :returns: true if the Box was successfully transformed, false otherwise.
