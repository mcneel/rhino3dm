   .. py:method:: MakePiecewiseBezier(setEndWeightsToOne: bool) -> bool

      Clamps ends and adds knots so the NURBS curve has Bezier spans (all distinct knots have multiplicity = degree).

      :param setEndWeightsToOne: If true and the first or last weight is not one, then the first and last spans are re-parameterized so that the end weights are one.

      :returns: true on success, false on failure.



   .. py:method:: Reparameterize(c: float) -> bool

      Use a linear fractional transformation to re-parameterize the NURBS curve. This does not change the curve's domain.

      The CV and knot values are values are changed so that output\_nurbs(t) = input\_nurbs(lambda(t)).

      :param c: re-parameterization constant (generally speaking, c should be > 0). The control points and knots are adjusted so that output\_nurbs(t) = input\_nurbs(lambda(t)), where lambda(t) = c\*t/( (c-1)\*t + 1 ). Note that lambda(0) = 0, lambda(1) = 1, lambda'(t) > 0, lambda'(0) = c and lambda'(1) = 1/c.

      :returns: true if successful.
