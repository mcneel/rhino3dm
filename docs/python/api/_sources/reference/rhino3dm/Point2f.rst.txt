rhino3dm.Point2f
================

.. py:class:: rhino3dm.Point2f
              Point2f(x: float, y: float)

   Represents the two coordinates of a point in two-dimensional space, using ``Single``-precision floating point numbers.


   .. py:method:: CompareTo(other: Point2f) -> int

      Compares this ``Point2f`` with another ``Point2f``.

      Coordinates evaluation priority is first X, then Y.

      :param other: The other ``Point2f`` to use in comparison.

      :returns: if this is identical to other
                -1: if this.X < other.X
                -1: if this.X == other.X and this.Y < other.Y
                +1: otherwise.
      :rtype: 0



   .. py:method:: DistanceTo(other: Point2f) -> float

      Computes the distance between two points.

      :param other: Other point for distance measurement.

      :returns: The length of the line between this and the other point; or 0 if any of the points is not valid.
