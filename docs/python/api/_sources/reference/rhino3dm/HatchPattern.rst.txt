rhino3dm.HatchPattern
=====================

.. py:class:: rhino3dm.HatchPattern
              HatchPattern(other: HatchPattern)

   Bases: :py:obj:`ModelComponent`


   Base class for all components in a model (document) and manages the index, id and other information common to this type of objects.

   This class parallels the C++ ON\_ModelComponent.

   .. py:property:: AlwaysModelDistances
      :type: bool


      Hatchpattern patterns are typically interpreted as distances on the printed output when printing. In this case AlwaysModelDistances is false (default). When set to true, the hatch pattern will be interpreted as being in world distances.


   .. py:property:: ComponentType

   .. py:property:: Index

   .. py:property:: PatternUnitSystem
      :type: UnitSystem


      Hatchpattern patterns are typically defined as distances on the printed output when printing. In this case PatternUnitSystem is UnitSystem.None (default). When set to any other unit system, the hatch pattern will be scaled acordingly.
