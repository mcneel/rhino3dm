rhino3dm.Material
=================

.. py:class:: rhino3dm.Material
              Material(other: Material)

   Bases: :py:obj:`ModelComponent`


   Base class for all components in a model (document) and manages the index, id and other information common to this type of objects.

   This class parallels the C++ ON\_ModelComponent.

   .. py:method:: CompareAppearance(material1: Material, material2: Material) -> int
      :staticmethod:


      Compares all the settings that affect the appearance of two materials (colors, reflection, textures, plug-in id), ignoring index, id, name and render material instance id.

      :param material1: The first material.
      :param material2: The second material.

      :returns: 0 when the materials look the same; otherwise a negative or positive value for ordering.
