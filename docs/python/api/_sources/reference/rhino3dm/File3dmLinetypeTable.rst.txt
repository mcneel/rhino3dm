rhino3dm.File3dmLinetypeTable
=============================

.. py:class:: rhino3dm.File3dmLinetypeTable

   Provides access to Linetypes in the 3dm file.


   .. py:method:: Add(item: Linetype) -> None

      Adds an item.

      :param item: The item to add.



   .. py:method:: Delete(item: Linetype | None) -> bool
                  Delete(index: int) -> None

      Flags a component as deleted.

      :param index: The index of the item to flag.

      :returns: True on success.



   .. py:method:: Dump() -> str

      Prepares a text dump of object table.

      :returns: A string containing the dump.



   .. py:method:: FindId(id: uuid.UUID) -> Linetype

      Uses the guid to find a model component. Deleted objects cannot be found by id. The guid is the value that is stored in the .Id property. In a single document, no two active objects have the same guid. If an object is replaced with a new object, then the guid persists. For example, if the \_Move command moves an object, then the moved object inherits its guid from the starting object. If the Copy command copies an object, then the copy gets a new guid. This guid persists through file saving/opening operations. This function will not find grip objects.

      :param id: ID of model component to search for.

      :returns: Reference to the rhino object with the objectId or null if no such object could be found.



   .. py:method:: FindIndex(index: int) -> Linetype

      Retrieves a Linetype object based on Index. This search type of search is discouraged. We are moving towards using only IDs for all tables.

      :param index: The index to search for.

      :returns: A Linetype, or null if none was found.



   .. py:method:: FindName(name: str) -> Linetype

      Finds a Linetype given its name.

      :param name: The name of the Linetype to be searched.

      :returns: A Linetype, or null on error.



   .. py:method:: FromAttributes(attributes: ObjectAttributes) -> Linetype

      Finds the linetype an object with the given attributes uses, following the attributes' linetype source (the layer, the object or the parent).

      :param attributes: The object attributes.

      :returns: The linetype from this table, or a copy of a built-in linetype (such as ``Linetype.Continuous``) when the attributes resolve to one.



   .. py:method:: FromLayerIndex(layerIndex: int) -> Linetype

      Finds the linetype of the layer with the given index.

      :param layerIndex: The index of the layer.

      :returns: The linetype from this table, or a copy of a built-in linetype (such as ``Linetype.Continuous``) when the layer uses one.



   .. py:property:: ComponentType
      :type: ModelComponentType


      Returns ``ModelComponentType.LinePattern``.


   .. py:property:: Count
      :type: int


      Returns the count of all items, including deleted ones.
