rhino3dm.BrepFaceList

class rhino3dm.BrepFaceList

Provides access to all the Faces in a Brep object.

Add(surface: Surface) → BrepFace
Add(surfaceIndex: int) → BrepFace

Create and add a new face to this list. An incomplete face is added. The caller must create and fill in the loops used by the face.

Parameters:

surfaceIndex – index of surface in brep’s Surfaces list

AddConeFace(vertex: BrepVertex, edge: BrepEdge, revEdge: bool) → BrepFace

Add a new face to the brep whose surface geometry is a ruled cone with the edge as the base and the vertex as the apex point.

Parameters:

  • vertex – The apex of the cone will be at this vertex. The north side of the surface’s parameter space will be a singular point at the vertex.

  • edge – The south side of the face’s surface will run along this edge.

  • revEdge – true if the new face’s outer boundary orientation along the edge is opposite the orientation of edge.

AddRuledFace(edgeA: BrepEdge, revEdgeA: bool, edgeB: BrepEdge, revEdgeB: bool) → BrepFace

Add a new face to the brep whose surface geometry is a ruled surface between two edges.

Parameters:

  • edgeA – The south side of the face’s surface will run along edgeA.

  • revEdgeA – true if the new face’s outer boundary orientation along edgeA is opposite the orientation of edgeA.

  • edgeB – The north side of the face’s surface will run along edgeA

  • revEdgeB – true if the new face’s outer boundary orientation along edgeB is opposite the orientation of edgeB

ClearPerFaceColors() → int

Removes all per face color overrides on the active level.

Per face colors are a mutable property on BrepFace and are set with BrepFace.PerFaceColor.

Returns:

Number of changed faces.

ExtractFace(faceIndex: int) → Brep

Extracts a face from a Brep.

Parameters:

faceIndex – A face index

Returns:

A brep. This can be null.

Flip(onlyReversedFaces: bool) → None

Flips the orientation of faces.

Parameters:

onlyReversedFaces – If true, clears all BrepFace.OrientationIsReversed flags by calling BrepFace.Transpose() on each face with a true OrientationIsReversed setting. If false, all of the faces are flipped regardless of their orientation.

RemoveAt(faceIndex: int) → None

Deletes a face at a specified index.

Parameters:

faceIndex – The index of the mesh face.

RemoveSlits() → bool

Remove slit trims and slit boundaries from each face.

Returns:

true if any slits were removed

ShrinkFaces() → bool

Shrinks all the underlying surfaces in this Brep. Sometimes the surfaces extend far beyond the trimming boundaries of the Brep Face. This function will remove those portions of the surfaces that are not used.

Returns:

true on success, false on failure.

StandardizeFaceSurface(faceIndex: int) → bool

Standardizes the relationship between a BrepFace and the 3d surface it uses. When done, the face will be the only face that references its 3d surface, and the orientations of the face and 3d surface will be the same.

Parameters:

faceIndex – The index of the face.

Returns:

true if successful.

StandardizeFaceSurfaces() → None

Standardize all faces in the brep.

property Count: int

Gets the number of brep faces.

property HasPerFaceColors: bool

True if one or more faces on the active level have per face color overrides.

Per face colors are a mutable property on BrepFace and are set with BrepFace.PerFaceColor.
