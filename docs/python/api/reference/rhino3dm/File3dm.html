rhino3dm.File3dm

class rhino3dm.File3dm

Represents a 3dm file, which is stored using the OpenNURBS file standard.

The 3dm format is the main Rhinoceros storage format.

Visit http://www.opennurbs.com/ for more details.

GetEmbeddedFileAsBase64(path: str, strict: bool) → str

The bytes of a file embedded in the model, base64 encoded (rhino3dm only).

Finds only the files Rhino’s renderer embedded, not ones added with EmbeddedFiles.Add. To read any embedded file, take it from File3dm.EmbeddedFiles and call its ToByteArray().

Parameters:

  • path – The embedded file’s path, or (not strict) just its name.

  • strict – True: the path must match exactly, case included. False (the default): the path or the file name matches, ignoring case.

Returns:

The file’s bytes as a base64 string, empty when no embedded file matches.

Write(path: str, options: File3dmWriteOptions | None) → bool
Write(path: str, version: int) → bool

Writes contents of this model to an openNURBS archive. If the model is not valid, then Write will refuse to write it.

Parameters:

  • path – The file name to use for writing.

  • version – Version of the openNURBS archive to write. Must be [2; current version]. Rhino can read its current version, plus earlier file versions except 1. Use latest version when possible. Alternatively, 0 is a placeholder for the last valid version.

Returns:

true if archive is written with no error. false if errors occur.
