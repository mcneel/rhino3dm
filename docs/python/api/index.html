rhino3dm.py

rhino3dm is a Python library for reading, writing and working with Rhino’s .3dm files and the geometry in them, without Rhino. The API is generated from RhinoCommon, and the documentation here is RhinoCommon’s own.

Important

Coming from rhino3dm 8.x? 9.2 is generated from RhinoCommon, and much of the API changed. Read Migrating to rhino3dm 9.2 (Python) first, and look up any 8.x name in Renamed and removed members (Python).

import rhino3dm

model = rhino3dm.File3dm()
circle = rhino3dm.Circle(rhino3dm.Point3d(0, 0, 0), 5.0)
model.Objects.AddCircle(circle)
model.Write("circle.3dm", 8)

Install with pip install rhino3dm.
