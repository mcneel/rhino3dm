  • new Ellipse(center, second, third): Ellipse

  • Initializes a new ellipse from a center point and the two semi-axes intersections.

    Parameters

    • center: Point3d

      A center for the ellipse. The average of the foci.

    • second: Point3d

      The intersection of the ellipse X axis with the ellipse itself.

    • third: Point3d

      A point that determines the radius along the Y semi-axis. If the point is at right angle with the (center - second point) vector, it will be the intersection of the ellipse Y axis with the ellipse itself.
