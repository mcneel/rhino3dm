Class MeshFace

Represents the values of the four indices of a mesh face quad.

If the third and fourth values are the same, this face represents a triangle.

StaticcompareTo

  • compareTo(meshFace, other): number

  • Compares this MeshFace with another MeshFace and returns a value of 1, 0, or -1, referring to dictionary order.

    Index evaluation priority is first A, then B, then C, then D.

    Parameters

    • meshFace: MeshFace
    • other: MeshFace

      The other MeshFace to use in comparison.

    Returns number

    0: if this is identical to other -1: if this < other. Priority is for index of corner A first, then B, then C, then D. +1: otherwise.

Staticrepair

  • repair(meshFace, points): boolean

  • Attempts to repair this mesh face by taking both face indexes and actual vertex locations into account.

    This function assumes the face is invalid and attempts to repair unconditionally. It is only worthwhile to call Repair on faces where IsValid returns false.

    Parameters

    • meshFace: MeshFace
    • points: Point3d[]

      Array of vertices with which to consider when repairing the face.

    Returns boolean

    true if the face was repaired, false if not.
