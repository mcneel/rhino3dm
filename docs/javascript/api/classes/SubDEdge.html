Readonlysharpness

sharpness: SubDEdgeSharpness

Gets or sets the sharpness of this edge.

The getter reports SubDEdgeSharpness.Crease for a crease edge; use GetSharpnessGetSharpness(false) to get SubDEdgeSharpness.Smooth for creases instead.

Setting this goes through the parent SubD so that the neighboring edges and vertices are updated too. Assign SubDEdgeSharpness.Smooth to make the edge smooth again.
