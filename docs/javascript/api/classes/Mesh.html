Class Mesh

      The 3D input points to be covered with the convex hull. At least four points are required, and they must not be coincident, colinear, or coplanar.

    A valid mesh if successful. If there were too few input points, or the input was degenerate (coincident, colinear, or coplanar), the result is null.

  • createQuickHull3D(pointCloud): Mesh

  • Attempts to create a 3d convex hull mesh from an input point cloud using the QuickHull algorithm. Hull faces whose shared edges are not clearly convex are merged, so faces of the resulting mesh may be triangles, quads, or larger convex polygons (returned as mesh ngons).

    Parameters

    • pointCloud: PointCloud

      The point cloud to be covered with the convex hull. At least four points are required, and they must not be coincident, colinear, or coplanar.
